# 人向文档文风(human-style)

> 适用:人读的文档(README/操作手册/教程/答辩材料)。与十判据同 DNA 的人类侧镜像——数字条↔判据 5(数值单源),渲染词条↔判据 3(修饰词无增益);不是另一套标准。方法:句式段落模式先行,负面词 grep 只兜底(shuorenhua)。

## 0. 保真合同(最高律,先于一切风格)

- 数字连修饰对象一起留:"300ms 内出安抚帧"≠"很快响应"
- 关系不改写:"展示潜力"≠"采用了"
- 范围/条件/否定/情态即事实:"仅二期""未启用""计划中"一个不能丢
- 抽象不擅自具体化:原文说"多路"不写"三路"
- 缺信息指出缺口,不补:写"未实测",不写"性能良好"

## 1. 四型语气卡(Diátaxis)

| 型 | 语气 | 要点 |
|---|---|---|
| Tutorial(教程) | 第二人称 | 开头承诺结果;每步可验证;原理不提前讲 |
| How-to(操作) | 标题=任务名 | 假设已上手;步骤编号;前置条件一行 |
| Reference(参考) | 零叙事零人称 | 条目同构可扫读;端点/字段/状态码护全(与接口契约纪律同构) |
| Explanation(解释) | 回答为什么 | 允许取舍观点;标题写成论点;不夹操作步骤 |

README 第一屏三问:是什么 / 给谁用 / 解决什么。

## 2. 负面模式清单

空洞总结段(综上/总之+复述)· 强制三连排比 · "值得注意的是"起手 · 不可证伪赞美词(强大/完善/优雅)· 散文段强行分点 · 元叙述(本文将介绍)· "不是X而是Y"壳 · 二元对比连用(一段≥2组)· 引号对仗金句(「X」翻译成「Y」式抽象对仗)· 戏剧化收尾词(命运/旅程类)· 口号式断片(破折号后无谓语)· 标题下复读 · 写旧版本史(墓志铭判据人类侧)· 伪深刻总结 · 没人问的辩解 · 万能正面结尾

## 3. 执行顺序

1. 划保护片段先锁:数字、版本、命令、路径、报错、引用原文、责任归属——套话句里混着证据时,删渲染词不删证据
2. 按 0/1 通读句式段落判型与保真,模式改写
3. 第 2 节负面清单 grep 兜底

顺序不颠倒;词表永远兜底不做先锋。

## 4. 完成判据

- 第 2 节可 grep 项零命中
- 整句空话不直删→进"待确认清单"呈人(=存疑停下问护栏的人向版)
