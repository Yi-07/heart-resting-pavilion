# CONTRIBUTING 骨架(贡献者协作规则)

> 触发器=团队协作规则成型(与 README 同批建立,README 协作内容拆出至此)。读者=动手改代码的队友(窄受众);README 管"是什么/去哪看",本文件管"怎么参与"。makeareadme 明示:GitHub 对 issue/PR 自动提示本文件。

- **环境搭建**:指向环境/操作手册(逐步骤,人做)
- **分支与提交**:分笔纪律(不同源改动分笔)+message 惯例(中文+改动明细)
- **验证路由**:改后端/前端/文档各跑什么检查(与 agent 入口同源的人向复述)
- **文档纪律**:契约以契约文件为准,代码核验通过后同步契约文档(同批次提交);改公共行为查 spec 同步;新代码落点边界表
- **agent 协作**:本项目用 coding agent 开发,agent 规则入口=CLAUDE.md;队友开 agent 前先读;文档审查走 doc-standards skill
