# ADR 骨架(决策记录)

> 一次决策一篇,文件名按「NNN-标题.md」;向前采用,取代而非静默改写:被取代篇保留原文、状态行注取代者,编号不复用。

**立档判据(建前三问,三项全真才立)**:难以反转?无上下文会令人惊讶?存在真实权衡?任一不真,记进度台账,不立 ADR。

**判别线**:动了机制/参数/契约才算架构级;纯实现细节不立。决策发生当下记;agent 起草,用户过目。

- 标题:决策一句话,动词句
- 状态:已接受 / 已被 NNN 取代
- 背景:约束+诱因,不写流程叙事
- 决策:定了什么,可执行表述
- 落选方案:每候选一行,为何输
- 后果:正面/负面/涟漪(同步改了哪些文档)
