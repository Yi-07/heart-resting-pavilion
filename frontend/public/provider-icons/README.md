# Provider Icons

The provider SVGs in this directory are adapted from the icon set shipped by
[cc-switch](https://github.com/farion1231/cc-switch/tree/main/src/icons/extracted).
They are kept as static assets so the app does not need a runtime request to
cc-switch or a remote icon CDN. If an asset is unavailable at runtime, the
model card falls back to the provider initial.
