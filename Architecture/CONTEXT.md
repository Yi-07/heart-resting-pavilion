## 路由与安全

**危机闸门**:L3 的规则硬判组件,作用于每条 user_input。

**分层判定**:分类器机制——规则先判明显 case,模糊才调 LLM,低 conf 兜底 collect;RAG 门控复用同一机制。阈值 → spec §4 L3。

**不变量**:全文档通行的铁律——危机判定只在后端 · emotion_label 不进路由 · 黑板=模板+全量 formulation+seq · 信念字段可留白 · 音频转写即弃。

**确定性条件边**:LangGraph 编排方式,纯 Python 条件函数派活,无 LLM 主管。
_避用_: 监督者 / supervisor / langgraph-supervisor

**停采后分析**:MVP 分析时机——STOP 后同步执行。
_避用_: 边采边算(二期专名"真·边采边算") / 停采集后再分析 / 降级档

**分析型/建议型分流**:已废除的旧设计(现=分析总结必给 + 心灵补给站懒生成)。
_避用_: 分流(描述现行机制时)

## 采集与黑板

**充分度**:采集完整度的度量(0~1)。计算与阈值 → spec §6。
_避用_: 完成度

**粗稿 / 精稿**:同一张模板图的两个深化阶段——快速研判标签开局 / 完整 formulation 收尾。

**快速研判**:规则/关键词级情绪标签,喂粗稿与 Live2D。

**两级标签**:快速研判(粗稿)+ RAG/LLM(精稿)的优先级链。

**情绪一源三用**:同一 emotion JSON{label,intensity} 驱动 Live2D 表情 / 黑板情绪字段 / TTS 情感标签。

**模板声明**:前端模板定义 {asset, fields};加模板=加一份声明,渲染器零改动。

**回合 / 会话**:回合=first_frame 到 done 的周期;会话=单 WS 连接生命周期(跨回合共享 seq 与上下文)。

## 产品组件

**心灵补给站**:方案书的用户入口(点击触发生成 + md 预览/导出)。
_避用_: 诊疗方案书 / 诊疗报告(医疗措辞红线)

**心灵补给站邀请语**:分析总结末尾的固定模板引导语(不让 LLM 自由发挥)。

**空窗期**:等待后端响应的时间窗,由第一帧/黑板渐进/语音安抚填充。
