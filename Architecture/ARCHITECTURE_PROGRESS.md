## 三、核心决策摘要

**架构**:三路路由(危机/直接答/多轮采集)· 危机闸门贯穿每轮 · 多轮采集 = 共情式对话(L4 管状态、L5 管话术)· formulation schema 按 Beck 认知概念化 · DrawProtocol 模板级(draw 传全量)。

**模板模型**:一个会话一个模板,粗稿/精稿**同一张图逐步深化**(表层→深层),数据填充;测试模板 3 个(`emotion_wheel`/`beck_formulation`/`stage_map`);"心理状态→模板"映射表后期维护。

**关键参数(可调常量)**:充分度高阈值默认 0.7(常态 2 轮,信念=bonus)/ 测试档 0.85(3 轮挖信念)· 心情选择器超时 10s · 轮数上限 2~3。

**契约**:8 消息(first_frame=回合起点/draw 全量/error 帧)· `mood_select` 上报后端喂记忆 · 危机判定只在后端。

**技术栈**:FastAPI + LangGraph + SQLite + Redis + Vue3/Vite/TS + SVG 自研黑板渲染器 + Live2D + CosyVoice 2/SenseVoice + DeepSeek/Ollama 双源 LLM。
