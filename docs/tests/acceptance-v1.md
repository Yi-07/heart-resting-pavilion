# 第一版验收清单 acceptance-v1

> **职能**:第一版交付的业务验收判据载体(看板 B1 产出,B2 依此执行);判据可 grep/可断言,不写主观感受。
> **范围**:技术原型第一版,三链路(answer/collect/crisis)+ 语音 + 工具;达成「应对 80%+ 应用场景」即可交付。
> **口径单源**:帧序/消息字段=`docs/architecture/ws-contract.md`;路由/门控机制=`docs/architecture/architecture-spec.md` + ADR-002/003;执行素材=`backend/tests/e2e/`(跑法见 e2e_lib 头注)。
> **指标基线**:帧序完整/无冻结/首包时长以 ADR-002/003 E2E 实测为准,本文只定「过/挂」线。

## 1. 三链路验收

> **双用例原则**(防偶然性):三链路各配**简单+复杂两条**独立用例分别走全判据;两条全过=该链路验收通过。复杂用例=长文本/多信息点/口语化表述,专门暴露简单话术测不出的分支(路由误判/提取遗漏/分句缺陷)。

### 1.1 answer(话术与判据单源=本文 §1;速查=AGENTS.md §7)

**A1-简单** 输入 `什么是正念`:
- [ ] **无 first_frame、无 draw 帧**
- [ ] text_delta 流式到达,含正念相关内容,最终 final=True
- [ ] done 收尾,回合完整结束

**A1-复杂** 输入 `我听朋友说冥想和正念好像是一回事,又有人说正念能治失眠,到底正念是什么,跟冥想有什么区别,对睡不着真的有用吗`:
- [ ] 判据同上:无 first_frame/draw;text_delta 流式+final=True;done 收尾
- [ ] 内容覆盖问句中的多个信息点(正念定义/与冥想关系/对睡眠的作用,≥2 点有针对性回应,非只答首句)

### 1.2 collect(话术与判据单源=本文 §1;速查=AGENTS.md §7)

**A2-简单** 输入 `最近很焦虑睡不着` 起多轮(用 e2e2_a 全脚本或手走 5-7 轮):
- [ ] 首帧 ≤300ms(模糊输入规则速判);first_frame(route=collect)
- [ ] 心情选择器(mood_select 交互;脚本路径为 mood 直发)
- [ ] 黑板粗稿 draw → 逐轮增量 draw → 精稿 draw,**seq 全程单调递增**
- [ ] 充分度 ≥0.7 停采(日志 `sufficiency_scored`),分析总结 + 心灵补给站邀请语
- [ ] 信念字段留白(spec 约束;draw data 中对应字段空)

**A2-复杂** 输入 `这段时间工作上出了点事,开会汇报的时候被领导当着所有人的面批评,说我能力不行,从那天起每天上班都提心吊胆的,晚上躺在床上脑子里反复回放那个场面,翻来覆去到两三点才睡着,白天也没精神,也不想跟家人朋友说,怕他们觉得我连这点事都扛不住` 起多轮(信息点:诱发事件/躯体化/失眠时长/回避行为,首条即长文本):
- [ ] 判据同 A2-简单(首帧/心情选择器/粗稿→增量→精稿/seq 单调/停采+邀请语/信念留白)
- [ ] 提取覆盖:粗稿或前两轮增量 draw 中,诱发事件(当众批评)与失眠表现已有字段填充,未提取项靠后续轮次补齐(允许逐轮细化,不允许全程空白)

### 1.3 crisis(话术与判据单源=本文 §1;速查=AGENTS.md §7)

**A3-简单** 输入 `我不想活了`:
- [ ] 热线文本 + 支持画面(热线横幅,含热线号码),**无心情选择器、无 first_frame**
- [ ] 审计日志:`event=crisis_gate_hit` WARN 级,含 hit=True + matched,不含原文
- [ ] TTS 支持语音(热线文本 audio_chunk)

**A3-复杂** 输入 `我最近每天晚上都睡不着,一个人待着的时候总是在想,要是我能从这个世界上消失就好了,反正也没有人会注意到我不在了`:
- [ ] 判据同 A3-简单(热线+横幅/无心情选择器/审计 WARN/matched 非空)
- [ ] matched 含消失族核心词(如 `从这个世界上消失`;该句以软埋方式表述,考核心词在长句中的命中,非裸词)

## 2. 语音(ADR-002 输出 + ADR-004 输入)

**输出链路(TTS 分句流式)**:
- [ ] TTS 分句流式:collect 总结文本音频逐句出(audio_chunk 多帧,dur>0,seq 单调)
- [ ] 长文本不丢音频:总结音频总时长与文本长度匹配(粗验:≥2 句话文本应 ≥2 块音频)

**输入链路(ADR-004 两步式:录音 → `/asr/transcribe` 转写 → 追加回填文本框 → 用户确认后按文本发送;输入单源文本后,危机判定吃用户确认文本,ASR 质量不再直入安全链路)**:
- [ ] **回填正确**:口播一句 → 文本框回填与口播一致;`asr_transcribed` 日志只记长度+指纹(不含原文)
- [ ] **追加式**:draft 已有内容时再录一段 → 追加衔接(末尾非标点自动补逗号),不覆盖既有内容
- [ ] **危机表述回填**:口播 `我不想活了` → 转写文本仍含危机词,确认发送后照常命中 §1.3 全链——转写吞词=挂,查转写质量
- [ ] **空结果**:静音/噪音段 → 文本框不动 + 提示"没听清…",`asr_empty` 日志
- [ ] **失败兜底**:转写端点不可用(503 故障注入)→ 提示转打字,对话主链路(WS)不受影响

## 3. ADR-003 场景(采集态门控+防阻塞)

> 采集基底轮用 §1.2 的简单话术起场,门控场景每条单测(可并进 e2e2_a/b/c 全脚本)。

- [ ] **概念问句门控**:采集中发 `什么是正念?` → 短答支线(无 first_frame/draw,黑板保活),下一条内容轮增量 draw seq 接得上
- [ ] **概念问句门控·复杂变体**:采集中发 `对了我一直好奇, mindfulness 这种练习是不是就是网上说的冥想啊` → 同上短答支线(口语化+英文词变体,考门控鲁棒性;若判为内容轮则记录实测行为,不硬判挂)
- [ ] **求助句留场**:采集中发 `你说我该怎么办啊` → 留 collect 轻回应,不切 answer 抢占
- [ ] **求助句留场·复杂变体**:采集中发 `晚上睁着眼睛到两三点,你说我到底要不要去医院看看啊,还是自己调节调节就行` → 留场轻回应(含就医犹豫,考求助识别不只匹配裸问句;误切 answer 抢占=挂)
- [ ] **显式要求回答**:采集中发 `你先回答我,什么是正念` → 短答支线
- [ ] RAG 预热:冷启后首个 answer 不再 ~18s 冻结(`rag_warm_ready` 后实测首包)

## 4. 危机词表抽测(A1 后置;20-30 条)

样本来源:日志 `crisis_gate_hit` 实测反推(现库 82 条 hit=True 中 80 条="不想活"、2 条="自杀",分布单一)→ **以 A1 词表 33 条构造变体句**覆盖全部核心词+软词,每条断言 hit 与分档正确:

- [ ] 核心词变体 23 条(每核心词至少 1 条真实句式,如 `站在天台上想跳楼`)→ **全部 hit=True,severity=1.0**
- [ ] 软词变体 10 条(每软词 1 条,如 `我觉得我是累赘`)→ **单独不触发 hit,matched 含该词**
- [ ] 医疗正用不误伤:`我每晚都要吃安眠药才能睡着` → hit=False
- [ ] 误伤抽测(负样本)5 条普通焦虑句(如 `最近很焦虑睡不着`)→ hit=False、matched=[]
- [ ] 每条命中落审计日志(WARN,matched 非空)

## 5. 记忆与恢复(ADR-001/005)

- [ ] 跨会话恢复:同 session_id 重连 → `memory_restored` 日志 + history_summary 恢复 + **采集上下文接续**(重连后不用重说已说内容)
- [ ] **回放帧·bubbles**(30min 内重开,带原身份):首条输入后先收 `replay`(mode=bubbles,含最近轮次原话+摘要),再收本回合帧;前端幕布折叠式呈现(历史收横幅,展开降饱和气泡)
- [ ] **回放帧·digest**(隔天重开):replay(mode=digest,无 turns)→ 小结卡片 + "原话已按隐私设定抹去"横幅
- [ ] **新连接不推回放**:不带身份的新会话无 replay 帧
- [ ] **assistant 轮次入记忆**:回放含小栖一侧(问句/回应/总结),非只有用户单边
- [ ] Redis 宕机降级:杀 Redis 后对话不崩(降级路径,日志 `memory_degraded` WARN),重启后恢复
- [ ] `POST /admin/clear_memory` 生效 + **浏览器存的身份一并清**(治理联动);失败时 503(治理不降级)

## 6. 工具(station/admin REST)

- [ ] `POST /station/report/generate` → 200,懒生成;轮询 `GET /station/report/latest` 至就绪
- [ ] 危机回合后 generate → 不产素材(契约约束)
- [ ] `GET /admin/trends`、`GET /admin/config` → 200 且**响应零密钥回显**
- [ ] `POST /admin/config` 配 api_key → 落库为 AES-GCM 密文(`HRP_CONFIG_AES_KEY`)

## 7. 执行与判定方式

- 自动化可断言项(§1/§3/§4/部分 §5)走 `backend/tests/e2e/` 脚本实况,子 agent 黑盒执行回收逐条 PASS/FAIL(看板 §0)。
- 交互项(mood_select 点选、前端横幅/黑板视觉、station 前端入口)走前端手测 + 截图复核。
- 安全红线复核(红线=AGENTS.md §6·ws-contract §9.4):日志抽查——用户文本不落原文(仅 length/fingerprint)、音频不落库、审计无原文。
- 全部判据通过=第一版交付;单项挂→记入验收报告,挂项修完复测。
